Контрольные вопросы и ответы

1. Методы DOM для создания: document.createElement() для создания новых тегов (li, button) и parentElement.appendChild() для их вставки в дерево.

2. Обработчик события: С помощью метода addEventListener('click', function) или свойства onclick.

3. Проверка ввода: Использовать условие if (input.value.trim() !== "") перед вызовом функции добавления.

4. Визуальное отличие: Выполненным задачам добавляется CSS-класс (например, .completed), который устанавливает text-decoration: line-through и меняет цвет текста.

5. Сохранение между сеансами: Использовать API localStorage для записи данных в формате JSON через setItem и их чтения при загрузке через getItem.
