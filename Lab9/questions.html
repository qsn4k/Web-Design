Ответы на контрольные вопросы по JavaScript

1. Что такое "асинхронность" в JavaScript, и как она отличается от синхронного выполнения кода?

Синхронное выполнение означает, что код выполняется строго по порядку: каждая следующая операция ждет завершения предыдущей. Если одна задача занимает много времени, вся программа «зависает».

Асинхронность позволяет запускать длительные операции (например, запросы к серверу), не блокируя выполнение остального кода. Программа продолжает работать, а когда асинхронная задача завершается, JavaScript возвращается к обработке ее результата.

2. Какой объект в JavaScript используется для работы с асинхронными операциями? Объясните его основные состояния.

Для работы с асинхронными операциями используется объект Promise (промис). Он может находиться в одном из трех состояний:

  • Pending (Ожидание) — начальное состояние, операция еще не завершена.
  • Fulfilled (Исполнено) — операция завершена успешно, и у нас есть результат.
  • Rejected (Отклонено) — произошла ошибка в ходе выполнения операции.

3. Чем отличаются async/await от использования метода .then() у промисов? Какие преимущества они дают?

Метод .then() использует цепочки вызовов (колбэки), что при большом количестве задач может привести к запутанному коду. async/await — это «синтаксический сахар» над промисами.

Преимущества async/await:

  • Код выглядит как синхронный, его легче читать и поддерживать.
  • Избегается вложенность (callback hell).
  • Удобнее работать с условиями и циклами внутри асинхронных функций.

4. Как обрабатываются ошибки в асинхронных функциях с использованием async/await? Приведите пример.

Ошибки обрабатываются с помощью стандартной конструкции try...catch. Если промис внутри блока try возвращает ошибку, управление переходит в блок catch.

Пример:
async function getData() {
  try {
    let response = await fetch('url');
    let data = await response.json();
  } catch (error) {
    console.log("Произошла ошибка: " + error);
  }
}

5. Что такое "Event Loop" в JavaScript, и как он связан с выполнением асинхронного кода?

Event Loop (цикл событий) — это механизм, который постоянно проверяет стек вызовов и очередь задач. Поскольку JavaScript однопоточный, он может делать только одну вещь за раз.

Связь проста: когда асинхронная операция (например, таймер или запрос) завершается, ее результат попадает в очередь задач. Event Loop ждет, пока основной стек выполнения станет пустым, и только после этого переносит задачи из очереди в стек для выполнения.
