Контрольные вопросы и ответы по JavaScript

1. Как проверить, является ли число целым, и какие методы JavaScript можно использовать для этой проверки?

Ответ: Самый надёжный и современный метод — это статический метод Number.isInteger(), который возвращает true, если значение является числом и не имеет дробной части.

// Пример использования Number.isInteger()
            Number.isInteger(10);     // true
            Number.isInteger(10.5);   // false
            Number.isInteger(Infinity); // false

2. Как извлечь подстроку из строки, начиная с определённой позиции и заданной длины? Напишите пример функции.

Ответ: Используйте метод String.prototype.slice(), вычислив конечный индекс как сумму начальной позиции и требуемой длины.

/**
            * Извлекает подстроку, начиная с позиции start, длиной length.
            */
            function extractSubstrByLength(str, start, length) {
            // slice(Начальный индекс, Начальный индекс + Длина)
            return str.slice(start, start + length);
            }

            const text = "JavaScript";
            console.log(extractSubstrByLength(text, 4, 6)); // "Script"

4. Как проверить, содержит ли объект определённое свойство, и в чём разница между использованием in и hasOwnProperty?

Ответ: Оператор in проверяет наличие свойства в самом объекте **ИЛИ** в его цепочке прототипов (включая наследуемые свойства). Метод hasOwnProperty() проверяет наличие свойства **только** в самом объекте (его собственное свойство).

Метод Наследование Описание
'prop' in objВключаетПроверяет свойство в объекте и его прототипах.
obj.hasOwnProperty('prop')ИсключаетПроверяет только собственное свойство объекта.

5. Чем отличаются методы forEach и map при работе с массивами? Приведите примеры их использования.

Ответ: forEach используется для итерации и выполнения побочных эффектов (например, вывод, изменение внешней переменной), и возвращает undefined. map используется для трансформации (преобразования) каждого элемента в новый элемент, и возвращает **новый массив** той же длины.

Пример map (Трансформация):

const tempsCelsius = [10, 15, 20];

            // map создает НОВЫЙ массив, преобразуя каждый элемент
            const tempsFahrenheit = tempsCelsius.map(celsius => {
            return celsius * 9/5 + 32;
            });

            // tempsFahrenheit: [50, 59, 68]

Пример forEach (Побочный эффект):

const numbers = [1, 2, 3];
            let sum = 0; // Внешнее состояние

            // forEach изменяет ВНЕШНЕЕ состояние (sum) и ничего не возвращает
            numbers.forEach(num => {
            sum += num; 
            });

            // sum: 6
